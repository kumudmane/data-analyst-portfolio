# E-Commerce Sales & Profitability Analysis

## Objective
Analyze 9,000+ retail transactions to identify profitability drivers, regional performance trends, customer-level profitability patterns, and pricing opportunities that support data-driven business decision-making.

## Project Overview
This project focuses on analyzing large-scale retail transaction data using SQL and Tableau to uncover key sales and profitability trends. The analysis emphasizes regional performance, discount impact, customer profitability, and product strategy to help businesses optimize pricing, reduce losses, and improve strategic focus.

## Tools Used
- Excel → Data cleaning and preprocessing
- SQL → Profitability analysis, KPI generation, and business querying
- Tableau → Interactive dashboard design and visualization

## Dataset
Retail transactional dataset containing 9,000+ records including customer orders, sales, discounts, profit, product categories, and regional details.

## Analysis Performed
- Profitability Drivers Analysis
- Regional Sales & Profit Trends
- Loss-Making State Identification
- Discount Impact Analysis
- Customer-Level Revenue vs Profitability Analysis
- Product Focus Evaluation
- Interactive Dashboard with Filter-Based Decision Support

## Key Insights
- Analyzed 9,000+ retail transactions using SQL to identify profitability drivers and regional performance trends
- Identified loss-making states and over-discounting issues, enabling targeted pricing and cost optimization strategies
- Highlighted that high-revenue customers are not always profitable, supporting customer-level profitability analysis
- Built a Tableau dashboard to support data-driven decision-making on product focus and pricing strategies

## Business Recommendations
- Reduce excessive discounting in low-profit regions
- Reassess pricing strategy in loss-making states
- Focus on customer profitability, not just customer revenue
- Prioritize profitable products and categories for strategic growth
- Use dashboard insights to guide regional and pricing optimization
