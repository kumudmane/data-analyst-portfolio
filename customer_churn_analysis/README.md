# Customer Churn Analysis

## Objective
Analyze customer churn data to identify key factors contributing to customer attrition and uncover actionable business insights for improving customer retention.

## Project Overview
This project focuses on analyzing Telco customer churn data to understand why customers leave, which customer segments are most at risk, and what business factors influence churn behavior.

## Tools Used
- Excel → Data cleaning and preparation
- SQL → Data analysis and KPI generation
- Tableau → Data visualization and dashboard creation

## Dataset
Telco Customer Churn Dataset containing customer demographics, account details, service subscriptions, billing information, and churn status.

## SQL Analysis Performed
- Overall Churn Rate (main KPI)
- Contract Type vs Churn Rate
- Customer Tenure Group Analysis
- Monthly Charges vs Churn
- Payment Method Impact on Churn

## Key Insights
- Month-to-month contract customers showed the highest churn rate
- Customers with shorter tenure were more likely to churn
- Higher monthly charges were associated with increased churn probability
- Customers using electronic check payment methods had higher churn rates

## Business Recommendations
- Improve retention strategies for month-to-month customers
- Focus on onboarding and engagement for new customers
- Review pricing strategies for high monthly charge customers
- Target high-risk payment segments with retention campaigns
